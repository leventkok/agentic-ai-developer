# ELI5

Q: What's an AI agent, and how is it different from a regular computer program?
A: Regular computer programs are doing ordinary things but AI agent can do complete tasks, multi-step loop, exc. 


# Scenario
Q: A smart thermostat learns your schedule and pre-heats the house. What type of agent is it and why?
A: It's a Goal-Based Agent because, it has plan steps toward a goal. 

# Deep Dive
Q: Compare a goal-based agent vs a utility-based agent. When would you pick each?
A: Goal-Based just doing plan steps toward a goal but Utility-based agents pickin best options by score. If i design single purpose program like "Booking cheapest flight to anywhere" i choose goal-based agent. But, If i design multi-step purpose program like "If a design a program that scans and compiles statistics on reviews of apps in the store" i choose Utility-based agent.
